### Вывод стандарта C++ 23
Новый стандарт C++ 23 предоставляет новые функции:
###### print
```cpp
std::print("Hello, {}", "World!");
```
Использует фигурные скобки для вывода переменных, поступающих как последующие аргументы функции, есть так же спецификаторы.

###### println
```cpp
std::println("Hello, {}", "World!");
```
Так же как функция [[#print]], но в в конце вывода добавляет символ переноса строки.

Для кастомизации выводимых данных используются спецификаторы, которые позволяют выводить данные в нужном формате и форме

**Пример:**
```cpp
int num = 42; 
std::println("Hex: {:#x}, Bin: {:#b}", num, num); 
std::println("Leading zeros: {:05d}", num); 
std::println("Sign: {:+d} and {: d}", num, num);
```
> [!NOTE] Terminal Output
> ```text
> Hex: 0x2a, Bin: 0b101010
 >Leading zeros: 00042
> Sign: +42 and  42
> ```

---
Для их использования нужно импортировать подбиблиотеку `#inlcude <print>`
#### Таблица спецификаторов
| Выравнивание и заполнение  | <   |
| ---------| ------------------------------------------------------|
| `{:10}`  | Задает минимальную ширину в 10 символов (по умолчанию выравнивание по левому краю для текста, по правому —  для чисел).|                                          
| `{:<10}` | Выравнивание по **левому** краю. |
| `{:>10}` | Выравнивание по **правому** краю.|
| `{:^10}` | Выравнивание по **центру**.      |
| `{:*^10}`| Выравнивание по центру, а пустые места заполняются символом `*`. |
| **Целые числа**  | <  |
| `{:d}` | Обычный десятичный вывод (Decimal, применяется по умолчанию). |
| `{:b}` / `{:B}` | Двоичный формат (Binary) в нижнем или верхнем регистре (например, `1010`). |
| `{:#b}` | Двоичный формат с префиксом `0b` (например, `0b1010`). |
| `{:o}` | Восьмеричный формат (Octal). |
| `{:x}` / `{:X}` | Шестнадцатеричный формат (Hex) в нижнем или верхнем регистре (например, `2f` или `2F`). |
| `{:#x}` | Шестнадцатеричный формат с префиксом `0x` (например, `0x2f`). |
| `{:05d}` | Заполнение числа **ведущими нулями** до общей ширины в 5 символов (например, `00042`). |
| `{:+d}` | Всегда выводить знак: `+` для положительных чисел и `-` для отрицательных. |
| `{:-d}` | Выводить знак только для отрицательных чисел (по умолчанию). |
| `{: d}` | Выводить пробел перед положительным числом (полезно для выравнивания в столбик с отрицательными). |
| **Числа с плавающей точкой** | < |
| `{:.2f}` | Фиксированная точка с точностью ровно **2 знака после запятой**. |
| `{:e}` / `{:E}` | Научный формат с экспонентой (например, `3.14e+00`). |
| `{:g}` / `{:G}` | Автоматический выбор: переключается между `f` и `e` в зависимости от того, какая запись короче для данного числа. |
| `{:#}` | Принудительный вывод десятичной точки, даже если дробная часть равна нулю (например, `42.`). |
| **Символы, строки и лошический тип** | < |
| `{:s}` | Строковый формат (применяется к `std::string`, `const char*` по умолчанию). |
| `{:.5s}` | Обрезает строку, выводя **только первые 5 символов**. |
| `{:c}` | Выводит целое число как символ ASCII (например, `65` превратится в `A`). |
| `{:b}` | Выводит `true`/`false` для типа `bool` в виде текста (по умолчанию). |
| `{:d}` | Выводит `bool` в виде числа (`1` или `0`). |

```cpp
	std::println("[{:<10}]", "text");
	std::println("[{:>10}]", "text");
	std::println("[{:^10}]", "text");
	std::println("[{:*^10}]", "text");

	std::println("[{:10}]", 42);
	std::println("[{:<10}]", 42);
	std::println("[{:>10}]", 42);
	std::println("[{:05d}]", 42);

	std::println("[{:+d}]", 42);
	std::println("[{:-d}]", 42);
	std::println("[{: d}]", 42);

	std::println("[{:d}]", 255);
	std::println("[{:b}]", 255);
	std::println("[{:#b}]", 255);
	std::println("[{:o}]", 255);
	std::println("[{:#o}]", 255);
	std::println("[{:x}]", 255);
	std::println("[{:X}]", 255);
	std::println("[{:#x}]", 255);
	std::println("[{:#X}]", 255);

	std::println("[{:+010x}]", 255);

	std::println("[{:f}]", std::numbers::pi);
	std::println("[{:.2f}]", std::numbers::pi);
	std::println("[{:e}]", std::numbers::pi);
	std::println("[{:G}]", std::numbers::pi);
	std::println("[{:#.0f}]", 3.0);

	std::println("[{:*>+#12.4f}]", std::numbers::pi);

	std::println("[{:s}]", "hello");
	std::println("[{:.3s}]", "hello");
	std::println("[{:_^10.3s}]", "hello");

	std::println("[{:c}]", 65);

	std::println("[{:s}]", true);
	std::println("[{:d}]", true);

```
