После определения переменной можно присвоить некоторое значение. Присвоение переменной начального значения называется инициализацией. В C++ есть три вида инициализации:

- Нотация присваивания (assignment notation)  
- Функциональная нотация (functional notation)
- Инициализация в фигурных скобках (braced initialization)


### Нотация присваивания

Суть нотациии присваивания - с помощью оператора присваивания (знак "равно" или =) переменной передаем некоторое значение:
```cpp
int age = 20;
```

### Инициализация в фигурных скобках

При инициализации `braced initialization` после названия переменной в фигурных скобках указывается ее значение:
```cpp
int age {38};   // braced initialization
```
В данном случае переменная будет иметь значение 38.

##### Главные особенности
- *Запрет сужения типов* [[Преобразования типов#^bca7a9|[1]]]:
&nbsp;&nbsp;&nbsp;&nbsp; Компилятор выдаст ошибку, если вы попытаетесь записать большее число (например, double или int со значением 300) в переменную меньшего размера (например, char), что повышает безопасность кода. [[Преобразования типов#^611af5|[2]]]
<br>
- *Инициализация по умолчанию*: 
&nbsp;&nbsp;&nbsp;&nbsp; Запись `int x {};` или `double y {};` гарантированно обнуляет переменную (0 для чисел, пустые значения для других типов). 
<br>
- *Устранение неоднозначностей*:
&nbsp;&nbsp;&nbsp;&nbsp; Помогает избежать известной проблемы C++, когда компилятор путает объявление функции и создание объекта с круглыми скобками.  

**Пример:**
```cpp
#include <iostream>
  
int main()
{
    int age1 (23.5);
    int age2 = 24.5;
    std::cout<<"Age1 = " << age1 << "\n";
    std::cout<<"Age2 = " << age2 << "\n";
}
```
Здесь переменным `age1` и `age2`, которые представляют тип int, то есть целое число, присваивается дробное значение - `23.5` и `24.5` соответственно. Но в большинстве компиляторов этот код скомпилируется.

Теперь пример с инициализацией через фигурные скобки:
```cpp
#include <iostream>
  
int main()
{
    int age {22.5};
    std::cout<<"Age = " << age << "\n";
}
```
Здесь переменной `age`, которая также представляет **целое число**, также присваивается **дробное значение** - `22.5`. Однако теперь при компиляции многие компиляторы сообщат об ошибке. Например, вывод компилятора g++:

> [!NOTE] Terminal Output
> ```text
> hello.cpp: In function 'int main()':
> hello.cpp:5:15: error: narrowing conversion of '2.25e+1' from 'double'
>  to 'int' [-Wnarrowing]
>     5 |     int age1 {22.5};
> ```

<br>

> [!INFO] 
> Наиболее предпочтительный метод из-за своих особенностей.

<br>

### Функциональная нотация

При функциональной нотации после названия переменной в круглых скобках указывается ее значение:
```cpp
int age (38);
```

###

Во всех трех случаях присваиваемое переменной значение может представлять сложное вычисляемое выражение.

**Пример:**
```cpp
int age1 {22 + 5};
int age2 (22 + 5);
int age3 = 22 + 5;
```


Можно сразу инициализировать несколько переменных:
```cpp
int age1 {22}, age2 (23), age3 = 24;
```

#### **auto**
Иногда бывает трудно определить тип выражения. В этом случае можно предоставить компилятору самому выводить тип объекта. И для этого применяется спецификатор auto. При этом если определять переменную со спецификатором auto, эта переменная должна быть обязательно инициализирована каким-либо значением:
```cpp
auto number = 5;        // number имеет тип int
auto sum {1234.56};    // sum имеет тип double
auto distance {267UL};  // distance имеет тип unsigned long
```

На основании присвоенного значения компилятор выведет тип переменной. Неинициализированные переменные со спецификатором auto не допускаются:
```cpp
auto number;
```


### Кратко
В C++ 23 надо использовать присвоение через фигурные скобки, так безопасно оно проверяет тип при инициализации и присваивает ноль если внутри скобок ничего нету. Введено с C++ 11 так что и там можно. Равно устарело...
