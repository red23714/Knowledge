Пространство имен позволяет сгруппировать функционал в отдельные контейнеры. Пространство имен представляет блок кода, который содержит набор компонентов (функций, классов и т.д.) и имеет некоторое имя, которое прикрепляется к каждому компоненту из этого пространства имен. Полное имя каждого компонента — это имя пространства имен, за которым следует оператор `::` (оператор области видимости или scope operator) и имя компонента.


Примером может служить оператор `cout`, который предназначен для вывода строки на консоль и который определен в пространстве имен std. Соответственно чтобы обратиться к этому оператору, применяется выражение `std::cout`.

### Глобальное пространство имен

Если пространство имен не указано, то по умолчанию применяется глобальное пространство имен. применяется по умолчанию, если пространство имен не было определено. Все имена в глобальном пространстве имен такие же, как вы их объявляете, без прикрепления имени пространства имен:
```cpp
#include <iostream>
#include <string>
 
void print(const char*);
 
const char* message = "hello";
int main()
{
    print(message);
}
 
void print(const char* text)
{
    std::cout << text << std::endl;
}
```
Здесь определены функции `print` и `main` и константа **message** и не используется никакого пространства имен. Поэтому фактически функции `print` и `main` и константа `message` определены в глобальном пространстве имен. 

В принципе для обращения к ним также можно использовать оператор `::`, только без названия пространства имен, хотя это и избыточно:
```cpp
int main()
{
    ::print(::message);
}
```


### Определение пространства имен

Для определения пространства имен применяется ключевое слово namespace, за которым идет название имени пространства имен:
```cpp
namespace имя_пространства_имен
{
    // код пространства имен
}
```

После имени пространства имен идет блок кода, в который собственно помещаются компоненты пространства имен - функции, классы и т.д.


**Пример:**
```cpp
#include <iostream>
#include <string>
 
namespace hello
{
    const char* message = "hello work";
    void print(const char* text)
    {
        std::cout << text << std::endl;
    }
}
 
int main()
{
    hello::print(hello::message);
}
```
Здесь в пространстве **hello** определена функция `print` и константа `message`. И чтобы обратиться к этим компонентам вне пространства имен **hello**, надо использовать его имя. Внутри пространства имен к его компонентам можно обращаться без имени пространства имен.


### Вложенные пространства имен

Одно пространство имен может содержать другие пространства:
```cpp
#include <iostream>
#include <string>
 
namespace console
{
    namespace messages
    {
        const char* hello = "hello";
        const char* welcome = "Welcome";
        const char* goodbye = "Good bye";
    }
    void print(const char* text)
    {
        std::cout << text << std::endl;
    }
    void print_default()
    {
        std::cout << messages::hello << std::endl;
    }
}
 
int main()
{
    console::print(console::messages::hello);
}
```

Здесь в пространстве **console** определено вложенное пространство **messages**, которое содержит ряд констант. Для обращения к компонентам вложенного пространства имен также надо использовать его имя:
```cpp
void print_default()
{
    std::cout << messages::hello << std::endl;
}
```

Вне пространства имен **console** для обращения к подобным констанстам надо указывать всю цепь пространств имен:
```cpp
int main()
{
    console::print(console::messages::hello);
}
```


### Директива using

Директива **using** позволяет ссылаться на любой компонент пространства имен без использования его имени:
```cpp
#include <iostream>
#include <string>
 
namespace console
{
    const char* message = "hello";
    void print(const char* text)
    {
        std::cout << text << std::endl;
    }
}
 
using namespace console;    // подключаем все компоненты пространства console
 
int main()
{
    print(message); // указывать пространство имен не требуется
}
```

Однако такое подключение может привести к нежелательным последствиям, если в глобальном пространстве имен определяются компоненты с теми же именами (например, переменная message). В этом случае мы можем подключить только отдельные компоненты:
```cpp
#include <iostream>
#include <string>
 
namespace console
{
    const char* message = "hello";
    void print(const char* text)
    {
        std::cout << text << std::endl;
    }
}
 
using console::print;    // подключаем только функцию print
 
int main()
{
    print(console::message); // надо указывать пространство для message
}
```


### Псевдонимы пространств

Если название пространства длинное, то для него можно определить псевдоним:
```cpp
namespace псевдоним = название пространства имен;
```


**Пример:**
```cpp
#include <iostream>
#include <string>
 
namespace console
{
    namespace messages
    {
        const char* message = "hello";
    }
    void print(const char* text)
    {
        std::cout << text << std::endl;
    }
}
 
namespace mes = console::messages;
 
int main()
{
    console::print(mes::message); // обращаемся к message через псевдоним mes
}
```


### Кратко
Никто не использует namespace в своих программах, только для библиотек, чтобы функции не пересекались. Using не стоит использовать, запутаться легко, а простовлять потом std:: ну его нахуй. Псевдонимы ушли в прошлое, сейчас так стараются не делать, потому что это ебень полная, но знать важно для легаси кода.
