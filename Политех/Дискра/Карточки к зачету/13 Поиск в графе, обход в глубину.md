# Билет 13. Поиск в графе: обход в глубину

> **Вопрос:** поиск в графе: обход в глубину.

## Основа DFS

1. Выбираем текущую вершину $v$ (входящая, помеченная).
2. Смотрим её окрестность $N(v)$: ищем **непомеченные** вершины; выбираем любую, переходим в неё (помечаем и продолжаем).
3. Если непомеченных в окрестности нет — **возврат назад** к родительской вершине. Если возвращаться некуда — выход.

Название — depth first search: идём вглубь, пока можно.

## Классификация рёбер

Пусть проведён поиск в глубину. $T$ — множество **древесных рёбер** (по которым алгоритм шёл), все остальные рёбра — **обратные**, множество $B$.

## Рекурсивная процедура DFS(v)

```
procedure DFS(v);
  num[v] := i; i := i+1;
  for u ∈ list[v] do
    if num[u] = 0 then
      begin T := T ∪ {uv}; father[u] := v; DFS(u) end
    else if num[u] < num[v] and u ≠ father[v] then
      B := B ∪ {uv};
```

Обращение: `i := 1; T := ∅; B := ∅; обнулить num; для каждой вершины v с num[v] = 0: father[v] := ∅; DFS(v)` — внешний цикл нужен для несвязных графов; для связного достаточно одного `DFS(v0)`. Массивы: `num[v]` (0 — вершина не просмотрена), `father[v]` (родитель). Вершина «просмотрена» с начала работы `DFS(v)`, «использована» — когда процедура закончилась.

## Нерекурсивная версия

Рекурсия заменяется **стеком** $S$ вершин: положили $v$ в стек; пока стек не пуст — смотрим верхний $v = top(S)$; если есть непомеченный сосед $u$ — помечаем, добавляем ребро в $T$, father, push($u$); иначе pop($v$) — вершина использована. (Обратные рёбра в этой версии не вычисляются.)

## Теорема 8.1

Пусть $G$ — связный $(n,m)$-граф. Тогда:

1. поиск в глубину просматривает **каждую вершину в точности один раз**;
2. поиск в глубину требует **$O(n + m)$ операций**;
3. подграф $(V, T)$ графа $G$ является **деревом**.
