# Билет 3. Маршруты, цепи, циклы. Связность. Теорема о $n, m, k$

> **Вопрос:** маршруты, цепи, циклы. Понятие связности графа. Теорема связи между параметрами $n, m, k$ обыкновенного графа и следствия из неё.

## Маршруты, цепи, циклы

- **Маршрут** в графе $G$ — чередующаяся последовательность вершин и рёбер $v_0, e_1, v_1, \dots, e_t, v_t$, где $e_i = v_{i-1}v_i \in E_G$. Пишут $v_0 \to v_1 \to \dots \to v_t$; это $(v_0, v_t)$-маршрут. **Длина** — число рёбер (случай 0 не исключается). Если $v_0 = v_t$ — маршрут **замкнутый**.
- **Цепь** — маршрут без повторяющихся рёбер.
- **Простая цепь** — цепь без повторяющихся вершин (кроме, быть может, совпадающих концевых).
- Замкнутая простая цепь — **цикл**; незамкнутая — **открытая цепь**. Петля даёт цикл длины 1, пара кратных рёбер — циклы длины 2, цикл длины 3 — треугольник. Граф-цикл $C_n$ — $n$-угольник.
- **Лемма 1.2:** если существует $(u,v)$-маршрут, то существует и простая $(u,v)$-цепь.

## Связность

- Граф **связен**, если для любых двух различных вершин $u, v$ существует $(u,v)$-маршрут.
- Отношение связности $u \sim v \iff \exists (u,v)$-маршрут — отношение эквивалентности: рефлексивность (вершина связана с собой), симметричность, транзитивность.
- Классы эквивалентности $V_1, \dots, V_K$ порождают **компоненты связности** $G(V_i)$; каждый граф — дизъюнктивное объединение своих компонент связности. $(n, m, k)$-граф — $n$ вершин, $m$ рёбер, $k$ компонент. Связный граф: $k = 1$.
- **Разрезающее множество рёбер** — множество рёбер, удаление которых увеличивает число компонент; минимальное по включению — **разрез**. **Мост** — одноэлементный разрез. **Точка сочленения** — вершина, удаление которой увеличивает число компонент.
- **Лемма 1.3:** при удалении моста число компонент растёт **ровно на 1**. **Лемма 1.4:** при удалении рёбер разреза — тоже ровно на 1 (удалить все рёбра разреза, кроме одного; последнее становится мостом).

## Теорема 1.1

Для обыкновенного $(n,m,k)$-графа:

$$n - k \;\leq\; m \;\leq\; \frac{(n-k)(n-k+1)}{2}$$

**Верхняя оценка:** граф с $n$ вершинами, $k$ компонентами и максимумом рёбер — это $K_{n_1} \dot\cup K_{n_2} \dot\cup \dots \dot\cup K_{n_K}$ (компоненты полные). Если бы $n_2 > 1$, «переселив» вершину из второй компоненты в первую: теряем $n_2 - 1$ ребро, приобретаем $n_1 \geq n_2$ — рёбер стало больше при тех же $n, k$ — противоречие. Значит $n_2 = \dots = n_K = 1$ и все рёбра в $K_{n_1}$, где $n_1 = n - k + 1$:

$$\tilde{m} = \frac{(n-k+1-1)(n-k+1)}{2} = \frac{(n-k)(n-k+1)}{2}$$

**Нижняя оценка:** индукция по $m$. База $m = 0$: тогда $n = k$. Шаг: $G_1 = G - e$ — $(n, m-1, k_1)$-граф, причём $k_1 \leq k+1$ (если $e$ в цикле — $k_1 = k$; если мост — компонента рвётся ровно на две, $k_1 = k+1$). По предположению индукции $m - 1 \geq n - k_1 \geq n - k - 1$, откуда $m \geq n - k$.

### Следствия

1. Обыкновенный $(n,m)$-граф при $m > \dfrac{(n-2)(n-1)}{2}$ — связен.
2. Для произвольного $(n,m,k)$-графа $m \geq n - k$ (через редукцию графа).

Интуиция нижней оценки: добавление каждого ребра уменьшает $k$ не более чем на 1, чтобы из $n$ компонент получить $k$, нужно минимум $n-k$ рёбер.
