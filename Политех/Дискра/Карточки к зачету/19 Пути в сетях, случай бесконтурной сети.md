# Билет 19. Пути в сетях: случай бесконтурной сети

> **Вопрос:** пути в сетях: случай бесконтурной сети.

## Идея

В сети **без контуров** вершины можно перенумеровать так, что каждая дуга идёт от вершины с меньшим номером к вершине с большим. Тогда кратчайшие пути от $s$ считаются за один проход по вершинам в этом порядке.

## Две леммы

**Лемма 1.** В каждом бесконтурном орграфе есть хотя бы один **исток** (полустепень захода 0) и хотя бы один **сток** (полустепень исхода 0).

**Лемма 2.** Вершины бесконтурного орграфа можно перенумеровать так, что каждая дуга идёт из вершины с меньшим номером в вершину с большим. Лемма доказывается конструктивно — алгоритмом топологической сортировки (два варианта: от стоков к истокам и наоборот).

## Алгоритм топологической сортировки (от стоков)

**Вход:** бесконтурный орграф $G$. **Выход:** массив $Ind$ длины $n$, где для любой дуги $uv$: $Ind[u] < Ind[v]$.

1. $Num = n$; $H = G$.
2. Пока $Num > 0$:
   1. найти в $H$ **сток** $v$ (полустепень исхода 0);
   2. $Ind[v] = Num$; $Num = Num - 1$;
   3. $H = H - v$.

Корректность — из леммы 1: после удаления вершины граф остаётся бесконтурным, значит сток есть снова. Если граф задан списками смежности — время $O(m)$. Существование сортировки ⟺ лемма 2.

## Решение ЗКП

Пусть сеть отсортирована топологически и $s = 1$ (если нет — вершины с номерами меньше $Ind[s]$ просто недостижимы из $s$). Любой $(s, v_k)$-путь проходит через вершины с меньшими номерами ⟹ если $d(v_r)$ известны для всех $r < k$, то

$$d(v_k) = \min_{r < k}\{\, d(v_r) + c(v_r, v_k) \,\}$$

(справедливо по индукции). Вычисляем последовательно $d(v_2), d(v_3), \dots$

**Алгоритм** (вход: бесконтурная сеть $G$, вершина $s$; выход: $D$, $P$):
1. Топологически отсортировать вершины (массив $Ind$).
2. Для всех $i$: $D[i] = \infty$, $P[i] = s$, $UU[Ind[i]] = i$ (обратный массив: вершина с данным топологическим номером).
3. $D[s] = 0$.
4. Для $i = Ind[s]+1, \dots, n$: для всех $j \in list^{-}[UU[i]]$ (входящие соседи): если $D[UU[i]] > D[j] + c(j, UU[i])$ — обновить $D[UU[i]] = D[j] + c(j, UU[i])$, $P[UU[i]] = j$.
5. Вернуть $D, P$.

**Теорема.** Алгоритм решения ЗКП в случае бесконтурной сети имеет сложность **$O(m)$**.
