# Билет 18. Пути в сетях: метод Дейкстры

> **Вопрос:** пути в сетях: метод Дейкстры.

## Условия применимости

Сеть с **неотрицательными весами**. Тогда ЗКП точно имеет решение для достижимых вершин (контуров отрицательного веса быть не может), и существует алгоритм эффективнее Форда-Беллмана — **алгоритм Дейкстры**. В основе — **принцип жадности**: кратчайшие пути из $s$ вычисляются последовательно, на каждой итерации — кратчайший путь до очередной новой вершины.

## Инвариант алгоритма

$S = \{v_0 = s, v_1, \dots, v_k\}$ — вершины, для которых кратчайшие пути уже найдены; $d(v)$ — вес кратчайшего пути из $s$ в $v$; $F = V \setminus S$. Требуется:

1. $0 = d(v_0) \leq d(v_1) \leq \dots \leq d(v_k)$;
2. $d(v_k) \leq d(v)$ для всех $v \in F$.

То есть веса найденных кратчайших путей не убывают, и следующий найденный не может быть меньше предыдущих — это возможно именно из-за **неотрицательности весов**.

**Формула пересчёта:** для $v \in F$

$$D[v] = \min\{\, d(u) + c(u,v) \mid u \in S \,\}$$

— вес кратчайшего пути из $s$ «через $S$». Выбираем $w = \operatorname*{arg\,min}_{v \in F} D[v]$ («самая близкая к $S$» вершина) — для неё путь уже настоящий: $d(w) = D[w]$.

**Обоснование** (ключевой момент доказательства): для любого пути $P(s,w)$ возьмём первую его вершину $w_j \in F$ (предыдущая — в $S$). Тогда $D[w_j] \leq d(w_{j-1}) + c(w_{j-1}, w_j) \leq c(Q) \leq c(P)$, где $Q$ — подпуть до $w_j$ (неравенство — из-за неотрицательных весов). Плюс $D[w] \leq D[w_j]$ ⟹ $D[w] \leq c(P)$ для любого пути ⟹ $d(w) = D[w]$. Аналогично $d(w) \leq d(v)$ для всех остальных $v \in F$ — инвариант сохраняется.

## Алгоритм

**Вход:** матрица весов $C$, начальная вершина $s$. **Выход:** массивы $D$ (веса кратчайших путей) и $P$ (предшественники).

1. $D[s] = 0$, $P[s] = s$, $F = V \setminus \{s\}$, $S = \{s\}$.
2. Для всех $v \in F$: $D[v] = C[s,v]$ (или $+\infty$), $P[v] = s$.
3. Для $k = 1, \dots, n-1$:
   1. для всех $v \in F$: для всех $w \in list[v] \cap S$: если $D[w] + C[w,v] < D[v]$ — обновить $D[v]$, $P[v] = w$;
   2. выбрать $mv \in F$ с минимальным $D$ (если минимум $= +\infty$ — все оставшиеся недостижимы, стоп);
   3. $S = S \cup \{mv\}$, $F = F \setminus \{mv\}$.
4. Вернуть $D, P$.

**Сложность: $O(n^2)$** — на порядок ниже, чем у Форда-Беллмана.
