# Билет 12. Гамильтоновы графы

> **Вопрос:** гамильтоновы графы.

## Определения

- **Гамильтонова цепь** — незамкнутая простая цепь, проходящая через **каждую вершину графа точно один раз**.
- **Гамильтонов цикл** — цикл, проходящий через каждую вершину графа.
- Граф **гамильтонов**, если обладает гамильтоновым циклом.
- Для орграфов: **полугамильтонов** — обладает гамильтоновой цепью; **гамильтонов** — гамильтоновым циклом.
- Названы в честь Уильяма Гамильтона (1859): игра — обойти все 20 вершин **додекаэдра** по рёбрам по одному разу и вернуться. Другие задачи: рассадить компанию за круглым столом (по бокам — знакомые); задача о шахматном коне (обойти конём все 64 поля по одному разу и вернуться).

## Сложность проблемы

Вопрос существования гамильтоновых цепей/циклов внешне похож на эйлеров, но: простой и эффективный критерий для эйлеровых цепей есть (чётность степеней), а **поиск эффективного критерия существования гамильтонова цикла — одна из труднейших нерешённых задач теории графов**. Достаточно изучать обыкновенные графы.

## Достаточные условия гамильтоновости

- **Последовательность степеней** $d_1 \leq d_2 \leq \dots \leq d_n$. Последовательность $d$ **мажорируется** последовательностью $d'$, если $d_i \leq d'_i$ для всех $i$. **Лемма 1:** добавление одного ребра делает последовательность степеней мажорирующей прежнюю.

**Теорема 3.3 (Хватал, 1972).** Пусть $G$ — обыкновенный граф, $n \geq 3$, $d_1 \leq \dots \leq d_n$. Если для любого натурального $k$ верна импликация

$$d_k \leq k < \frac{n}{2} \;\longrightarrow\; d_{n-k} \geq n - k,$$

то $G$ гамильтонов. (Без доказательства.)

**Следствия (без доказательства):**
1. **Теорема Дирака (1952):** $d_k \geq \dfrac{n}{2}$ для любого $k$ ⟹ гамильтонов.
2. **Теорема Оре (1960):** $\deg u + \deg v \geq n$ для любых двух различных несмежных $u, v$ ⟹ гамильтонов.
3. $d_k > k$ для любого $k$ с $1 \leq k \leq \dfrac{n}{2}$ ⟹ гамильтонов.

## Гамильтоновы орграфы

**Теорема 3.4 (Гуйя-Ури).** Орсвязный $n$-орграф, у которого $\deg^+ v \geq \dfrac{n}{2}$ и $\deg^- v \geq \dfrac{n}{2}$ для любой вершины, — гамильтонов. (Без доказательства.)

**Турнир** — орграф, основание которого — полный граф (любые две вершины соединены ровно одной дугой, петель нет; модель спортивных турниров). Турнир может быть негамильтоновым (источник — вершина, из которой дуги только выходят, в цикл не попадает: в цикл надо «войти»).

**Теорема 3.5 (Редеи, Камион).**
1. Любой турнир **полугамильтонов**.
2. Любой **связный** турнир **гамильтонов**.
