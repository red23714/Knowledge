# Билет 7. Понятия леса, дерева. Критерий дерева. Критерий леса

> **Вопрос:** понятия леса, дерева. Критерий дерева. Критерий леса.

## Определения

- **Лес** — ациклический граф (граф без циклов).
- **Дерево** — связный ациклический граф.
- Лес не содержит петель и кратных рёбер, т.е. является обыкновенным графом.

## Теорема 2.3 (критерий дерева)

Для $(n,m)$-графа $G$ следующие условия эквивалентны:

1. $G$ — дерево;
2. $G$ — связный граф и $m = n - 1$;
3. $G$ — ациклический граф и $m = n - 1$;
4. любые две вершины соединены **единственной** простой цепью;
5. $G$ — ациклический граф, и добавление любого нового ребра приводит к появлению **точно одного** цикла.

**Схема доказательства:**

- **(1)⟹(2):** индукция по $m$, что в дереве $m = n-1$. База $m=0$: $n=1$. Шаг: любое ребро $e$ дерева ациклическое ⟹ $G - e$ распадается на две компоненты $G_1, G_2$ — деревья; по индукции в каждой рёбер на 1 меньше, чем вершин; складывая и возвращая ребро $e$, получаем $m = n - 1$.
- **(2)⟹(3):** если бы было циклическое ребро $e$, то $G - e$ — связный $(n, m-1)$-граф; по следствию 2 теоремы 1.1 $m - 1 \geq n - 1$, противоречие с $m = n - 1$.
- **(3)⟹(4):** сначала связность: компоненты ациклического графа — деревья, в каждой $m_i = n_i - 1$, значит $m = n - K$; вместе с $m = n-1$ даёт $K = 1$. Затем единственность цепи — от противного: две различные простые $(u,v)$-цепи $P_1, P_2$; беря длиннейшее общее начало $Q$ (сразу после $x$ цепи расходятся в разные вершины $y \neq z$), получаем: ребро $f = xz$ не лежит в $P_1$, объединение цепей без $f$ связно ⟹ $f$ — не мост ⟹ $f$ лежит в цикле — противоречие с ацикличностью.
- **(4)⟹(5):** из единственности цепей следует отсутствие циклов (в т.ч. петель: петля дала бы две простые $(u,u)$-цепи). Добавляем ребро $q = v\omega$: возникает цикл «простая $(v,\omega)$-цепь + $q$», и он единственный в силу единственности цепи.
- **(5)⟹(1):** любые две вершины соединены цепью (связность) + ацикличность ⟹ дерево.

**Следствие:** неодноэлементное дерево имеет **по крайней мере две висячие вершины**.

## Критерий леса

**Лемма 2.4.** $G$ — произвольный $(n, m, K)$-граф. $G$ является лесом $\iff$ $m = n - K$.

**Доказательство:** ($\Rightarrow$) в каждой компоненте-дереве рёбер на 1 меньше, чем вершин ⟹ $m = n - K$. ($\Leftarrow$) если $G$ — не лес, отбрасыванием рёбер получаем $(n, m_1, K)$-лес, $m_1 = n - K$, но $m > m_1$ — противоречие.
