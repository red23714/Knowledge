# Билет 8. Цикломатическое число и ранг графа. Остовы графа и их свойства

> **Вопрос:** циклотомическое число и ранг графа. Остовы графа и их свойства.

## Остовы

- В связном графе, удаляя по ребру из каждого цикла, приходим к **остовному дереву** — остовному подграфу-дереву. Для получения из $(n,m)$-графа нужно удалить $m - n + 1$ рёбер.
- Для $(n,m,K)$-графа: объединение остовных деревьев компонент — **остовный лес (остов)**; удаляем $m - n + K$ рёбер. Остов — **максимальный ациклический подграф** графа.
- Остов может быть построен за время $O(m)$, например обходом в глубину.

## Цикломатическое число и ранг

Для $(n,m,K)$-графа:

- $r^*(G) = m - n + K$ — **цикломатическое число** (сколько рёбер надо удалить до остова);
- $r(G) = n - K$ — **ранг** графа.

## Свойства (леммы)

**Лемма 2.5.**
1. $G$ ациклический $\iff$ $r^*(G) = 0$ (вытекает из леммы 2.4).
2. $G$ содержит **единственный** цикл $\iff$ $r^*(G) = 1$. (⟸: если $e$ в единственном цикле, $G - e$ — остов ⟹ $r^* = 1$; ⟹: $G = T + e$ для остова $T$, добавление ребра к компоненте остова даёт ровно один цикл по теореме 2.3.)

**Лемма 2.6.** Любой ациклический подграф графа $G$ содержится в некотором его остове.

**Лемма 2.7.** Пусть $S$ и $T$ — остовы графа $G$. Для любого ребра $e \in S$ существует ребро $f \in T$ такое, что $S - e + f$ — тоже остов (обмен ребром).

## Теорема 2.4 (Кирхгофа, 1847)

Число остовов в связном неодноэлементном обыкновенном графе $G$ равно **алгебраическому дополнению любого элемента матрицы Кирхгофа** $B(G)$. (Без доказательства; вспомнить: все алгебраические дополнения матрицы Кирхгофа равны — лемма 2 из темы «Представление графов».)

**Следствия:**
1. $\operatorname{rank} B(G) = r(G) = n - K$ — ранг графа равен рангу его матрицы Кирхгофа.
2. Число остовов в полном графе $K_n$ равно $n^{n-2}$.

## Теорема 2.5 (Кэли, 1897)

Число **помеченных деревьев** порядка $n$ (деревьев на множестве вершин $1, 2, \dots, n$) равно $n^{n-2}$ — эквивалент следствия 2: остовы $K_n$ ↔ помеченные деревья.
