# Билет 14. Поиск в графе: обход в ширину

> **Вопрос:** поиск в графе: обход в ширину.

## Основа BFS

1. Выбираем текущую вершину $v$ (помеченная), делаем её просмотренной.
2. Помечаем **всю** её окрестность $N(v)$ (непомеченных соседей), кладём их в очередь; извлекаем следующую помеченную вершину из очереди и повторяем пункт 1.
3. Пока очередь не пуста.

Название — breadth first search: обрабатываем вершины «слоями» по удалённости от старта.

## Процедура BFS(v)

```
procedure BFS(v);
  Q := nil; Q <= v; num[v] := i; i := i+1;
  while Q ≠ nil do
    begin
      u <= Q;                      { извлечь из очереди }
      for w ∈ list[u] do
        if num[w] = 0 then
          begin
            Q <= w; father[w] := u;
            num[w] := i; i := i+1; T := T ∪ {uw};
          end
    end
```

Внешний цикл по всем вершинам с `num[v] = 0` — для несвязных графов. Используются те же массивы $num$, $father$ и множество древесных рёбер $T$. **Полезно сравнить:** $BFS$ получается из **нерекурсивной** $DFS$ заменой **стека на очередь**.

## Теорема 8.7

Пусть $G$ — связный $(n,m)$-граф. Тогда:

1. поиск в ширину просматривает каждую вершину **в точности один раз**;
2. требует **$O(n + m)$ операций**;
3. подграф $(V, T)$ является **деревом**.

## Свойства BFS, отличающие его от DFS

(Обозначения: $w_1, w_2, \dots$ — вершины в порядке пометки, $h(v)$ — «уровень» вершины в дереве поиска.)

1. Вершина $w_k$ — отец $w_l$ $\iff$ $k = \min\{ i \mid w_i \in list(w_l) \}$.
2. Если отцы вершин $w_p, w_q$ — вершины $w_k, w_l$ и $p \leq q$, то $k \leq l$.
3. Если $1 \leq p \leq q \leq n$, то $h(w_p) \leq h(w_q)$ (уровни не убывают).
4. Если $w_p, w_q$ смежны и $p < q$, то $h(w_q) - h(w_p) \leq 1$ (уровни соседей отличаются не больше чем на 1).
5. **Расстояние** в графе от корня $w_1$ до произвольной вершины $v$ равно $h(v)$.

## Применение

Задача о кратчайшей цепи: в связном графе найти кратчайшую цепь из данной вершины $v_0$ в произвольную $v$. Решение: провести BFS из $v_0$ (расстояние — это $h(v)$), а затем восстановить цепь по массиву $father$.
