# Билет 6. Представление графов на ЭВМ

> **Вопрос:** представление графов на ЭВМ.

Обозначение: $M(n,m)$ — объём памяти для представления графа на $n$ вершинах с $m$ рёбрами. Граф с линейно упорядоченными (занумерованными) вершинами — **нумерованный**.

## Матрица смежности

$A = A(G) = (a_{ij})_{n \times n}$, где $a_{ij}$ — **число рёбер**, соединяющих $v_i$ и $v_j$ (петля при $i = j$ учитывается **дважды**).

- Симметрична: $a_{ij} = a_{ji}$; сумма по строке $i$ равна $\deg v_i$.
- Для обыкновенных графов — бинарная с нулевой главной диагональю.
- Для одного графа матриц несколько (зависит от нумерации); они получаются друг из друга одинаковой перестановкой строк и столбцов, т.е. **подобны**.
- **Характеристический многочлен** графа — характеристический многочлен любой из его матриц смежности (корни — собственные значения — не зависят от нумерации). **Спектр графа** — все корни с учётом кратности. Для $K_3$: спектр $\{2, -1, -1\}$.
- $M(n,m) = O(n^2)$.

**Теорема 2.** Если $A$ — матрица смежности графа без петель и $A^l = (l_{ij})$, то $l_{ij}$ — **число $(v_i, v_j)$-маршрутов длины $l$**.

Доказательство — индукция по $l$: при $l = 1$ это определение матрицы смежности; переход — разбивка маршрутов по предпоследней вершине $v_s$: $l_{ij} = \sum_s \xi_{is} a_{sj}$ (где $\xi_{is}$ — число маршрутов длины $l-1$), т.е. умножение матриц. Теорема верна и для графов с петлями, если считать каждую петлю имеющей два обхода.

**Быстрое возведение в степень:** $A$ вещественная симметричная ⟹ ортогонально подобна диагональной: $A = T^{-1}DT$ (спектральная теорема; на диагонали $D$ — спектр графа). Тогда $A^l = T^{-1}D^lT$, а $D^l$ — просто $\lambda_i^l$ на диагонали — быстро даже для больших $l$.

## Матрица Кирхгофа

$$B(G) = \operatorname{diag}[\deg v_i] - A(G), \qquad \beta_{ij} = \begin{cases} \deg v_i, & i = j \\ -1, & i \neq j, \ v_i \sim v_j \\ 0, & i \neq j, \text{ не смежны} \end{cases}$$

**Лемма 2:** алгебраические дополнения всех элементов матрицы Кирхгофа равны между собой.

## Матрица инцидентности

$I = I(G) = (i_{ke})_{n \times m}$ (граф дважды помечен: нумерация вершин и рёбер):
- неориентированный: $i_{ke} = 1$, если вершина $v_k$ инцидентна ребру $e$ (и $e$ — не петля), иначе 0;
- ориентированный: $1$ — вершина начала дуги, $-1$ — конца, $0$ — не инцидентна.

В каждом столбце ненулевых элементов не более двух (петля — один) ⟹ много нулей, способ неэкономен: $M(n,m) = O(n \cdot m)$.

**Лемма 3.** Для обыкновенного графа $G$ и матрицы инцидентности $I$ его ориентации $H$:

$$B = I \cdot I^T$$

## Списки

- **Списки смежности** — массив указателей на списки смежных вершин (элемент списка: номер вершины + указатель на следующий). Неориентированные: $M(n,m) = O(n + 2m)$; орграфы: $O(n + m)$.
- **Список рёбер** — по строке на ребро: номера двух инцидентных вершин. $M = O(2m)$. По списку рёбер легко построить матрицу инцидентности.
