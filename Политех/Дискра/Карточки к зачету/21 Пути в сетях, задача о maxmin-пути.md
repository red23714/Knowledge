# Билет 21. Пути в сетях: задача о maxmin-пути

> **Вопрос:** пути в сетях: задача о maxmin-пути.

## Постановка

- Для пути $P: s = v_0 \to v_1 \to \dots \to v_k = v$ его **пропускная способность**:

$$c(P) = \min\{\, c(v_{i-1}, v_i) \,\}$$

— вес пути теперь **не сумма, а минимум** из весов дуг: вес самого слабого, самого «узкого» звена (как прочность цепи — по слабейшему звену).

- **Задача о maxmin-пути:** среди всех $(s,v)$-путей найти путь с **максимальной** пропускной способностью («задача об узком месте»).
- Прикладная задача (транспортная): дорожная сеть с мостами; вес дуги — минимальная грузоподъёмность мостов на участке ($\infty$, если мостов нет). Maxmin-путь из $s$ в $v$ — маршрут, позволяющий провезти **самый тяжёлый груз**, нигде не обрушив мост.
- Пример: сеть $s \to a (5), s \to b (2), a \to b (3), a \to t (1), b \to t (4)$. Пути из $s$ в $t$: $s\to a\to t$: $\min(5,1)=1$; $s\to b\to t$: $\min(2,4)=2$; $s\to a\to b\to t$: $\min(5,3,4)=3$ — maxmin-путь, хотя идёт с «крюком».

## Модификация алгоритма Дейкстры

Работает для произвольной сети с **неотрицательными весами**. Тот же принцип жадности: растим множество $S$ вершин с уже найденными maxmin-путями.

- $dm(v)$ — максимальная пропускная способность среди всех $(s,v)$-путей; $S = \{s\}$, $dm(s)$ фиксируется конечным стартовым значением.
- Инвариант: для $v \in S$, $w \in F = V \setminus S$: $dm(v) \geq dm(w)$.
- Для $w \in F$:

$$D(w) = \max\{\, \min\{\, dm(v),\ c(v,w) \,\} \mid v \in S \,\}$$

(доехать до $w$ через готовую вершину $v$: путь ограничен либо ответом $dm(v)$, либо новым звеном $c(v,w)$ — что меньше; берём лучший вариант).

- Очередная вершина: $D(w^{*}) = \max\{D(w) \mid w \in F\}$ — добавляем вершину с **максимальным** $D(w)$; $dm(w^{*}) = D(w^{*})$.

**Трассировка примера:** $S=\{s\}$: $D(a) = \min(dm(s), 5) = 5$, $D(b) = 2$ ⟹ берём $a$, $dm(a)=5$. Шаг 2: $D(b) = \max(2, \min(5,3)) = 3$, $D(t) = \min(5,1) = 1$ ⟹ берём $b$, $dm(b) = 3$ (больше прямой дуги $c(s,b)=2$!). Шаг 3: $D(t) = \max(1, \min(3,4)) = 3$ ⟹ $dm(t) = 3$. Итог: maxmin-путь до $t$ — $s \to a \to b \to t$, пропускная способность 3.

## Отличия от обычной Дейкстры

| | Дейкстра (кратчайший путь) | Maxmin-модификация |
|---|---|---|
| Вес пути | Сумма весов дуг | Минимум весов дуг |
| Что копим | Наименьший вес пути $d$ | Наибольшая пропускная способность $dm$ |
| Пересчёт | $d[w] = \min(d[w], d[v] + c(v,w))$ | $D(w) = \max_v \min(dm(v), c(v,w))$ |
| Кого добавляем в $S$ | С **минимальным** $d$ | С **максимальным** $D$ |

Структура алгоритма та же — жадно расширяем множество «готовых» вершин по одной за шаг.
