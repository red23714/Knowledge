# Билет 16. Задача о минимальном остове. Алгоритм Прима

> **Вопрос:** задача нахождения минимального остова в графе. Алгоритм Прима.

## Стратегия II («поглощающий алгоритм»)

Отличие от Краскала: минимальный остов ищется **для каждой компоненты связности** отдельно — растёт **одно дерево** из стартовой вершины (а не лес из многих), и нет необходимости отдельно искать компоненты — они получаются автоматически.

**Процедура $MinTree(v, k)$:**
1. $H = \{v, \varnothing\}$, пометить $v$ числом $k$, найти $Ext(H)$.
2. Пока $Ext(H) \neq \varnothing$: взять ребро минимального веса $e \in Ext(H)$; добавить в дерево; пометить вторую концевую вершину числом $k$; обновить $Ext(H)$.

**Общая процедура:** все вершины помечены 0; $K = 0$; пока есть вершины с меткой 0: выбрать такую вершину $v$, $K = K + 1$, запустить $MinTree(v, K)$.

## Алгоритм Прима-Дейкстры (MinTree)

Для обновления $Ext(H)$ и поиска минимального ребра используются два массива:
- $d[v]$ — **минимальный вес ребра**, соединяющего $v$ с текущим растущим деревом ($\infty$, если такого ребра нет);
- $near[v]$ — вершина дерева, «ближайшая» к $v$; т.е. $d[v] = c(v, near[v])$.

На каждом шаге достаточно выбрать вершину $v \notin H$ с минимальным $d[v]$ — соответствующее ребро уже «закешировано» в массивах.

**Вход:** граф $G$, вершина $v$. **Выход:** дерево минимального веса компоненты, содержащей $v$.

1. $W = V \setminus \{v\}$, $H = \{v, \varnothing\}$.
2. Для всех $i$: $near[i] = v$, $d[i] = c(i, v)$.
3. Пока true:
   1. если $W = \varnothing$ — вернуть $H$;
   2. выбрать $w \in W$ с минимальным $d[w]$;
   3. если минимум $= \infty$ — вернуть $H$ (остальные вершины недостижимы из $v$);
   4. $H = H + e$, где $e = (w, near[w])$; $W = W \setminus \{w\}$;
   5. для всех $w_i \in W$: если $d[w_i] > c(w_i, w)$ — положить $d[w_i] = c(w, w_i)$, $near[w_i] = w$.

**Сложность:** $O(n^2)$ операций (цикл по шагам × поиск минимума по $W$; пересчёт $d, near$ после каждого добавления).

## Сравнение стратегий

| | Стратегия I (Краскал) | Стратегия II (Прим-Дейкстра) |
|---|---|---|
| Что растёт | Лес из многих деревьев | Одно дерево от стартовой вершины |
| Сортировка рёбер | Да, всех $m$ | Нет |
| Ключевая структура | Массив компонент $M$ (DSU) | Массивы $d[\cdot]$, $near[\cdot]$ |
| Сложность | $O(m \log m)$ | $O(n^2)$ |
| Выгоднее на | Разреженных графах | Плотных ($m \approx n^2$) |

На одном и том же графе оба алгоритма дают минимальный остов **одинакового веса** (сам набор рёбер при равных весах может отличаться).
