# Билет 24. Задача о максимальном потоке: метод Эдмондса-Карпа

> **Вопрос:** задача о максимальном потоке: метод Эдмондса-Карпа.

## Идея

Проблема произвольного выбора цепей в методе Форда-Фалкерсона решается так: **увеличивать поток вдоль кратчайшей по числу дуг $f$-дополняющей $(s,t)$-цепи**. Тогда гарантируется максимальный поток и оценивается число итераций.

- $(v,w)$-цепь $P$ — **$f$-ненасыщенная**, если $h(P) > 0$ (величины $h(e)$ считаются как прежде: прямая — $c(e)-f(e)$, обратная — $f(e)$). Дуги, где $h(P) = h(e)$, — **узкие места цепи**.
- $d_k(v,w)$ — длина (число дуг) кратчайшей $f_k$-ненасыщенной $(v,w)$-цепи ($\infty$, если нет).
- **Лемма 1:** $d_k(s,v) \leq d_{k+1}(s,v)$ и $d_k(v,t) \leq d_{k+1}(v,t)$ — расстояния не убывают.
- **Лемма 2:** если дуга $e$ использовалась как прямая (обратная) на итерации $k$ и как обратная (прямая) на итерации $l > k$, то $d_k(s,t) + 2 \leq d_l(s,t)$.
- **Теорема 1 (Эдмондс, Карп, 1972):** при выборе кратчайших по числу дуг дополняющих цепей построение максимального потока требует не более $\dfrac{m(n+2)}{2}$ итераций.

## Поиск цепи — поиск в ширину с пометками

Дерево поиска растёт из $s$; помечаются только вершины, через которые может пройти дополняющая цепь. Массивы:

- $h[v]$ — метка ($\infty$, если вершина не помечена; как только помечена — существует $f$-ненасыщенная цепь с $h(P) = h[v]$);
- $Prev[v]$ — вершина, из которой помечена $v$;
- $ch[v] = +1$, если $v$ помечена по **прямой** дуге; $-1$ — по **обратной**.

**Правила пометки вершины $v$ из помеченной $w$** (пометить можно, если):

- прямая дуга: $c(w,v) - f(w,v) > 0$, метка $h[v] = \min(h[w],\, c(w,v) - f(w,v))$;
- обратная дуга: $f(v,w) > 0$, метка $h[v] = \min(h[w],\, f(v,w))$.

Если обе дуги $(v,w)$ и $(w,v)$ подходят — любая. Поиск (модифицированный BFS, очередь $Q$) заканчивается: достигли $t$ ⟹ цепь есть, строится по меткам $Prev$; очередь опустела, $t$ не достигнут ⟹ дополняющей цепи нет — поток максимален.

## Алгоритмы

**Алгоритм 1 — процедура Labeling** (вход: матрицы $C$, $F$, вершины $s, t$; выход: $h$, $ch$, $Prev$):
1. $h[v] = \infty$ для всех; $Q \leftarrow s$, $Prev[s] = 0$.
2. Извлечь $w$ из $Q$; для всех $v \neq s$ проверить условия пометки (прямая/обратная дуга) и помечать, добавляя в очередь.
3. Повторять, пока $h[t] = \infty$ и $Q \neq \varnothing$.

Сложность Labeling — сложность BFS: $O(n^2)$.

**Алгоритм 2 — Эдмондса-Карпа** (вход: сеть, $s$, $t$; выход: матрица потока $F$, величина $vf$):
1. $F = 0$, $vf = 0$.
2. Labeling; если $h[t] < \infty$: пройти от $t$ по $Prev$ до $s$; для каждой дуги цепи: $ch = +1$ ⟹ $F[w,v] + h[t]$, $ch = -1$ ⟹ $F[v,w] - h[t]$; $vf = vf + h[t]$; повторить.
3. Вернуть $F$, $vf$.

**Теорема 2:** алгоритм Эдмондса-Карпа имеет сложность **$O(n^5)$**. Если сеть задана списками смежности — модификация Labeling даёт $O(m^2 n)$, что иногда лучше.
