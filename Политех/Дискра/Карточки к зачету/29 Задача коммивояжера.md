# Билет 29. Задача коммивояжера. Метод ветвей и границ. Приближённые алгоритмы

> **Вопрос:** задача коммивояжера. Метод ветвей и границ. Приближённые алгоритмы решения задачи коммивояжера: методы «ближайшего соседа», «ближайшей вставки» и «наименьшего остова».

## Каркас вопроса (что нужно уметь рассказать)

1. **Постановка задачи коммивояжера:** найти самый дешёвый замкнутый маршрут (цикл), проходящий через каждую вершину ровно один раз, в полном взвешенном графе (матрица расстояний).
2. **Метод ветвей и границ:** точный метод — ветвление множества маршрутов на подмножества + отсечение по нижним оценкам (границам) стоимости маршрута в подмножестве.
3. **Приближённые алгоритмы** (быстрые, но не гарантия оптимума):
   - «ближайшего соседа» — из текущей вершины идти в ближайшую непосещённую;
   - «ближайшей вставки» — строить цикл, вставляя на оптимальное место ближайшую вершину;
   - «наименьшего остова» — связать через минимальный остов + превратить его в цикл.

⚠️ Все формулировки выше — общие представления, **не** из заметок; перед зачётом переписать по лекции.
