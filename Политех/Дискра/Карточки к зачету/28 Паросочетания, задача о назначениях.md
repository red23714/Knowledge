# Билет 28. Паросочетания в двудольном графе: задача о назначениях

> **Вопрос:** паросочетания в двудольном графе: задача о назначениях.

> [!warning] В заметках тема раскрыта частично
> Полного отдельного конспекта по задаче о назначениях нет — постановка и модель есть в заметке [[Паросочетания в двудольных графах]], плюс упоминание в [[Задача о полном паросочетании. Алгоритм Куна]]. Метод решения (венгерский алгоритм для задачи о назначениях с весами) в заметках не расписан — дописать из лекции.

## Постановка (задача 3 из тройки задач)

Пусть сверх условий задачи о полном паросочетании ($n$ рабочих, $n$ работ) для каждой пары «рабочий–работа» известна **стоимость** $c(x, y)$ выполнения работником $x$ работы $y$. Требуется так подобрать каждому рабочему определённый вид работ (каждому — ровно одну, каждую работу — ровно один исполнитель), чтобы **суммарная стоимость** выполнения всех работ была **минимальна**.

## Математическая модель

- Двудольный взвешенный граф $G = (X, Y, E, c)$: $X$ — рабочие, $Y$ — работы, ребро $xy$ ($x \in X$, $y \in Y$) — «рабочий $x$ может выполнить работу $y$», вес ребра — стоимость $c(x, y)$.
- Паросочетание $M \subseteq E$: каждое ребро $xy \in M$ — **назначение** рабочему $x$ работы $y$ (никакие два ребра паросочетания не имеют общей вершины ⟹ у каждого не более одной работы, каждая работа назначена не более чем одному рабочему).
- Задача о назначениях = среди **полных** паросочетаний ($|M| = n$) найти паросочетание **минимального суммарного веса** $c(M) = \sum_{e \in M} c(e)$.
- Три задачи образуют лестницу: (1) наибольшее паросочетание — «трудоустроить как можно больше»; (2) полное паросочетание — «трудоустроить всех»; (3) назначения — «трудоустроить всех и заплатить как можно меньше».

## Пример из заметки

3 рабочих, 3 работы; возможности и стоимости: $x_1$ — $y_1(4)$, $y_2(2)$; $x_2$ — $y_2(3)$, $y_3(5)$; $x_3$ — $y_1(6)$, $y_3(1)$. Два полных паросочетания:
- $M_A = \{x_1y_1, x_2y_2, x_3y_3\}$: вес $4 + 3 + 1 = 8$;
- $M_B = \{x_1y_2, x_2y_3, x_3y_1\}$: вес $2 + 5 + 6 = 13$.

Оба полные, дешевле $M_A$ ⟹ $M_A$ решает задачу.

## Что известно о методе решения

- Алгоритм Куна для **полного паросочетания** ([[Задача о полном паросочетании. Алгоритм Куна]]) — «часть метода Куна решения более общей задачи **о назначениях**»; свой метод Кун назвал **«венгерским алгоритмом»**.
- Для поиска полного паросочетания минимального веса заметками зафиксирован только каркас: построить полное паросочетание (Кун, $O(n^3)$) с учётом стоимостей; конкретной процедуры оптимизации стоимости в заметках нет.
