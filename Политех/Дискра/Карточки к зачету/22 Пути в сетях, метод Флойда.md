# Билет 22. Пути в сетях: метод Флойда

> **Вопрос:** пути в сетях: метод Флойда.

## Постановка

Дана сеть $G = (V, D, c)$ (матрица весов $C$: $C[i,j] = c(i,j)$ или $\infty$, если дуги нет). Найти кратчайшие пути **из каждой вершины в каждую** (задача (3) ЗКП).

Сравнение подходов: $n$ запусков Форда-Беллмана — $O(n^4)$; $n$ запусков Дейкстры или алгоритма для бесконтурной сети — $O(n^3)$, но с ограничениями (неотрицательные веса / отсутствие контуров). **Алгоритм Флойда** — $O(n^3)$ при любых весах (лишь бы не было отрицательных контуров) и без требований к структуре — его главное преимущество.

## Идея

Пусть $d_k(i,j)$ — длина кратчайшего пути из $v_i$ в $v_j$, все **промежуточные** вершины которого содержатся среди первых $k$ вершин $\{v_1, \dots, v_k\}$. Начало:

$$d_0(i,j) = C[i,j]$$

(промежуточных вершин нельзя — только прямая дуга). Рекуррентная формула при переходе $k \to k+1$:

$$d_{k+1}(i,j) = \min\big(d_k(i,j),\ d_k(i,k+1) + d_k(k+1,j)\big)$$

**Обоснование:** кратчайший путь $P$ с промежуточными из $\{v_1, \dots, v_{k+1}\}$ либо не содержит $v_{k+1}$ (тогда $d_{k+1} = d_k$), либо содержит — делим его на $(v_i, v_{k+1})$ и $(v_{k+1}, v_j)$; каждый подпуть кратчайшего пути сам кратчайший, и оба идут через первые $k$ вершин. Расстояние между парами — это $d_n(i,j)$.

## Алгоритм Флойда

**Вход:** матрица весов $C$. **Выход:** $D[i,j]$ — кратчайшие расстояния для всех пар; матрица $P$, где $P[i,j]$ — номер вершины, **предшествующей** $v_j$ в кратчайшем $(v_i, v_j)$-пути.

1. $D[i,j] = C[i,j]$, $P[i,j] = i$.
2. Для $k = 1 \dots n$:
   Для $i = 1 \dots n$:
   Для $j = 1 \dots n$:
   если $D[i,j] > D[i,k] + D[k,j]$, то $D[i,j] = D[i,k] + D[k,j]$; $P[i,j] = P[k,j]$.
3. Вернуть $D, P$.

Смысл обновления $P$: после «заезда через $k$» предшественник $j$ на пути из $i$ — тот же, что на пути из $k$ в $j$. Восстановление пути: идти по $P$ от $j$ назад до $i$. Массивы $D$ пересчитываются «на месте» — хранить все $d_k$ не нужно.

**Сложность:** три вложенных цикла по $n$ с константной работой внутри ⟹ **$O(n^3)$**.

## Пример трассировки

Сеть: $1\to2(3), 1\to3(7), 2\to3(1), 3\to4(2), 4\to1(5), 4\to2(-3)$ — есть **отрицательная** дуга, Дейкстра неприменима, Флойд работает (отрицательного контура нет: контур $2\to3\to4\to2$ весит $1+2-3=0$).

- $D_0 = C$: прямые дуги, $\infty$ там, где дуги нет.
- $k=1$: улучшается $D[4,3] = 12$ (путь $4\to1\to3$).
- $k=2$: $D[1,3] = 4$ ($1\to2\to3$), $D[4,3] = -2$ ($4\to2\to3$).
- $k=3$: $D[1,4] = 6$, $D[2,4] = 3$.
- $k=4$: $D[2,1] = 8$, $D[3,1] = 7$, $D[3,2] = -1$ (путь $3\to4\to2$).

Кратчайшее расстояние может быть **отрицательным** — это нормально при отсутствии отрицательного контура.
