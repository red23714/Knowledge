$\Omega$ — множество
Является кольцом, если соблюдается свойства:
1. $a + b = b + a, \ \forall a, b \in \Omega$(коммутативность)
2. $(a + b) + c = a + (b + c), \ \forall a, b, c \in \Omega$(ассоциативность)
3. $\exist \ \text{нулевой элемент} \ 0 \in \Omega; \ a + 0 = 0 + a = 0 \ \forall a \in \Omega$
4. $\forall a \in \Omega \ \ \exist -a \in \Omega$ (противоположность)
5. Умножение дистрибутивно относительно сложения
$$ a * (b + c) = ab + ac, \ \ (a + b) * c = ac + bc, \ \forall a, b, c \in \Omega$$

Виды колец:
1) Если $a * b = b * a$ (коммутативно), то кольцо $\Omega$ коммутативное.
2) Если $(a * b) * c = a * (b * c)$, то $\Omega$ ассоциативное.
3) Если в $\Omega \ \exist$ единичный элемент $e$: $a * e = e * a = a, \ \forall a \in \Omega$, то $\Omega$ — кольцо с единицей. 
4) Если ассоциативное, комутативное кольцо $\Omega$ с единицей <u>для каждого</u> ненулевого элемента $a$ существует обратный элемент $a^{-1} \in \Omega$:
$$a * a^{-1} = a^{-1} * a = e$$,
то $\Omega$ — поле.

Пример:

1) $2\mathbb{Z}$ (множество четных чисел)($n\mathbb{Z}, n > 1$) - коммутативное, ассоциативное кольцо
2) $\mathbb{Z}[i], \ \text{где} \ i^{2} = -1, \ i \notin \mathbb{Z}$

    $\uparrow$

    $\mathbb{Z}, i, \mathbb{Z} + i, \mathbb{Z} + \mathbb{Z}i = \mathbb{Z}[i]$ - кольцо целых гауссовых чисел

$|a + bi| = \sqrt{a^2 + b^2}$

3) Множества $\mathbb{Q}, \mathbb{R}, \mathbb{C}$ - поля
4) Квадратные матрицы с рациональными элементами — ассоциативное, некоммутативное кольцо с единицей с заданными операциями сложения и умножения
5) Множества квадратных матриц с рациональными элементами с обычной операцией сложения и операцией множения:
$$A * B = \frac{1}2(AB + BA)$$
— неассоциативное, коммутативное кольцо с единицей

Элемент $a \in \Omega$ делится($a \mathrel{\vdots} b$) на $b \in \Omega$ (или $b$ делит $a$ ($b | a$)), если делимость — это бинарное отношение).
$$\exist \ c \in \Omega : a = b * c$$

Пусть $a, b \in \Omega, b \ne 0$. Разделить $a$ на $b$ с остатком —
$$a = b * q + r$$,
где $q, r \in \Omega$ и либо $r = 0$, либо $N(r) < N(b)$
$$(N: \Omega \to \mathbb{R}_{\ge 0}) \text{ - норма}$$
$\to$ — сопоставление, проекция множества

## Теорема о делении с остатком 
$$\forall a, b \in \mathbb{Z}, b \ne 0$$
$$\exist ! q, r \in \mathbb{Z}, \text{что} \ a = qb + r; \ 0 \le r \le |b|$$
